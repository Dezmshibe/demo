MARULA TABLE CATERING - PLACEHOLDER WEBSITE
===========================================
Open index.html in any browser. No installation needed.

BEFORE PRESENTING / LAUNCHING
1. Brand: search all files for "Marula Table" and replace with the client's name.
   Also replace the phone numbers, email and address (index.html, js/script.js).
2. Photos: put images in the images/ folder. In index.html, inside each
   <div class="photo">, add:  <img src="images/yourfile.jpg" alt="Describe the event">
   and add class "has-img" to that div to hide the "Add photo" label.
3. Menus & prices: edit the menu-card blocks in index.html (all text is placeholder).
4. Enquiry form: open js/script.js and set CONFIG.endpoint to a Formspree
   (formspree.io) URL so enquiries land in the client's inbox. With no endpoint,
   the form opens the visitor's email app instead.
5. Colours: change the values at the top of css/style.css (:root).

HOSTING: upload the whole folder to Netlify, Vercel, GitHub Pages or any web host.
